Laptop Theft

Incident Summary

A laptop or computer device has been stolen, lost, or accessed without authorization.

Immediate Steps

1. Attempt to locate the device using tracking tools if available.
2. Log out of important accounts remotely.
3. Change passwords for email, banking, and work accounts.
4. Inform the employer if it is an office-issued device.
5. File a police complaint if theft is suspected.

Evidence To Preserve

1. Purchase invoice or proof of ownership.
2. Device serial number.
3. Screenshots of device location if available.
4. Login activity records.
5. CCTV footage if available.

Authorities To Contact

1. Local Police Station.
2. Employer or IT Administrator if applicable.
3. Cyber Crime Cell if unauthorized access occurs.

Important Notes

1. Monitor sensitive accounts for suspicious activity.
2. Record complaint and reference numbers.
3. Preserve all evidence related to device ownership.
4. Maintain copies of all communications.
